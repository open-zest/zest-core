Diagram 1: End-to-End System Process Flow (Origin Port → Sea Transit → Seaport → Rail Spine → Dry Port)

Architectural Shift: Legacy intermodal operations wait until physical vessel arrival (T+0) to resolve customs, commercial release, and rail slot allocation—forcing containers into a 57.39-hour stacking buffer. ZeST crystallizes the eFTI + NCTS T1 + Wagon Slot token at T-5 days (120 hours out at sea), turning the deep-sea port into an optical packet demultiplexer.

Diagram 2: Seaport Ingress BGP Router Flow (Quayside STS Crane → Optical Gate → Direct Rail Consist)

Graceful Degradation & Exception Isolation: Pre-cleared containers follow the bold green cut-through spine directly from the Ship-to-Shore (STS) crane onto single-zone block trains (ZONE_A_DUI through ZONE_F_BUD) with a 0.28h data verification buffer and zero yard re-handles. Any container missing a T-5 token is cleanly shunted to the isolated exception buffer without blocking the main rail transfer spine.

Diagram 3: Inland Dry Port Egress Access Switch Flow (Corridor Geofence → Direct Wagon-to-Chassis → 195 km Halo)

Eliminating Secondary Inland Dwell: When the single-zone block train crosses the T-2h corridor geofence, the ZeST token triggers automated local customs release and dispatches timed slot beacons to regional electric/short-haul trucks. Containers transfer directly from rail wagon to truck chassis (under 30-minute terminal turnaround), collapsing the rail-over-road breakeven distance to 195 km.
